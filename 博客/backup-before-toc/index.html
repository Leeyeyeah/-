欢迎来到我的博客！这里记录了我对技术、设计和生活的思考与分享。

关于本站

这是一个使用 Vue.js 构建的静态博客系统。文章采用 Markdown 编写，存放在 articles/ 目录下，系统会自动扫描并加载所有文章。

如何使用

  1. 在 articles/ 文件夹中创建 .md 文件
  2. 文章第一行以 # 标题 格式书写标题
  3. 在标题下方添加 > 日期：YYYY-MM-DD 和 > 分类：分类名 来指定元数据
  4. 刷新页面即可看到新文章

技术栈

  • Vue 3 — 前端框架
  • Markdown — 内容格式
  • marked — Markdown 解析
  • 原生 CSS — 样式设计
